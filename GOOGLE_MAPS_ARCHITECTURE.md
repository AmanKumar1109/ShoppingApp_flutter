## 2. Store Hub & Delivery Radius Configuration

All distance calculations and serviceability decisions are anchored relative to **The Grocery Hub** physical store location.

### Store Hub Location Constant (`BAHARAGORA_HUB`)
```json
{
  "lat": 22.2760625,
  "lng": 86.7193125,
  "name": "THE GROCERY HUB",
  "address": "Dadu Complex, near Shitla Mandir, Baharagora, Jharkhand 832101",
  "pincode": "832101"
}
```

### Delivery Radius Constraints
- **Max Radius Limit**: `5.0 km`
- **Calculation Standard**: Spherical Haversine Formula (`calculateDistance`).
- **Pincode Gatekeeping**: Primary local pincode is `832101`. Out-of-region prefixes (e.g. `831xxx`, `834xxx`, `721xxx`, `757xxx`) trigger service unserviceable status.

## 3. Key Modules & Services

### A. Dynamic SDK Loader (`googleMapsLoader.js`)
- Singleton promise loader preventing duplicate `<script>` tag injections.
- SDK URL: `https://maps.googleapis.com/maps/api/js?key=${VITE_GOOGLE_MAPS_API_KEY}&libraries=places,geometry`
- Async script injection with automatic fallback.

### B. Routing & Polyline Service (`routeService.js`)
- Utilizes `google.maps.DirectionsService` with `TravelMode.DRIVING`.
- Fetches exact turn-by-turn road polyline steps.
- Automatically falls back to straight-line navigation if network or API key is restricted.

### C. Map Tiles Strategy
- Integrates Google Maps Roadmap tile server via Leaflet tile layer:
  - Roadmap View: `https://{s}.google.com/vt/lyrs=m&x={x}&y={y}&z={z}` (subdomains `mt0`, `mt1`, `mt2`, `mt3`)
  - Satellite Hybrid: `https://{s}.google.com/vt/lyrs=s,h&x={x}&y={y}&z={z}`
